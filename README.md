# ATMega328-Based-UVG-Control-Board
ATmega328P-based board for controlling 4 DC motors using 4× PWM outputs and 2 quadrature encoders via interrupt-driven inputs. Includes 6× analog inputs, I²C, SPI, UART, Bluetooth module interface, and USB 2.0 connectivity. Powered via USB, DC barrel jack, or pin headers with automatic priority switching and 5 V regulation
